Let's play KB-09.

A recreation of Kevin's Roland SH-09, with a few cool extras. Linux x86-64 (AMD or Intel) · Version 1.8.3 · Standalone only.

Extract the entire ZIP first. Keep this folder together in a permanent location, such as your home Applications folder. This is a native Linux app: no DAW or plug-in installation is needed.

UNVERIFIED on a real Arch desktop. This first Linux release still needs confirmation of launch, audio playback and MIDI input on your system.

Open the standalone

  1. Open Start KB-09.sh. Your file manager may ask you to allow execution or choose “Run.” If it opens the script as text, open a terminal in this extracted folder and run bash './Start KB-09.sh'.
  2. Click AUDIO / MIDI and choose an output for your speakers or headphones. Enable your controller under Active MIDI inputs, or enable KEYBOARD to play on your computer keyboard.
  3. Select a factory preset and play. Start with a low listening volume.

You might get a security or launch-permission warning, depending on your Linux desktop and file manager. You might also get no warning at all.

The launcher marks the included synth executable and opens it. If an archive tool removed script permissions, running it through bash still works. Do not run KB-09 as root.

Want a desktop shortcut?

After putting the folder where you want to keep it, run Create desktop shortcut.sh (or bash './Create desktop shortcut.sh' in a terminal). Your desktop may ask you to allow launching the new shortcut. Keep the extracted synth folder in place; rerun this script if you move it. The standalone also offers to create a shortcut on first launch. If you skip that offer, you can run this script later.

Arch Linux requirements

A current 64-bit Arch desktop on AMD or Intel, with X11 or XWayland. The download targets standard x86-64, without requiring AVX. On Wayland, install xorg-xwayland if it is not already available.

If launch reports a missing library, update Arch and install the normal runtime packages:

sudo pacman -Syu --needed alsa-lib freetype2 fontconfig curl libx11 libxext libxinerama libxrandr libxcursor libxrender libxi libxcomposite

For a desktop already using PipeWire, pipewire-alsa routes ALSA applications through that audio system. Choose its default output in KB-09. JACK is also available when configured on your system. Start at 44.1 or 48 kHz with a 256- or 512-sample buffer. Arch package details.

The Linux build is tested in automated Linux checks. Your actual Arch desktop, audio device and MIDI controller still need a real playback check; report any setup problem below.

Linux launch warnings and audio troubleshooting

Linux desktops can differ in script permissions, display support and audio routing. These are proposed setup workarounds for a current Arch system; real desktop playback and MIDI remain UNVERIFIED.

Show Linux setup fixes

Script opens as text or says Permission denied: open a terminal in the extracted folder and run bash './Start KB-09.sh'. The launcher makes the synth executable. If execution is still denied, move the complete folder into your home folder; removable or network drives may prohibit execution. Run as your normal user, not root.

Missing shared library: on Arch, perform a normal full system update and install missing runtime dependencies. The runtime package list is alsa-lib freetype2 fontconfig curl libx11 libxext libxinerama libxrandr libxcursor libxrender libxi libxcomposite. For example: sudo pacman -Syu --needed alsa-lib freetype2 fontconfig curl libx11 libxext libxinerama libxrandr libxcursor libxrender libxi libxcomposite. Do not replace system libraries with downloaded individual files. A GLIBC_2.35 not found error means the system is older than this binary supports; use a supported, fully updated distribution.

No window on Wayland: KB-09 needs XWayland for its X11 interface. Confirm xorg-xwayland is installed and your desktop permits X11 applications. A remote/headless session without an X display cannot show the standalone window. Arch XWayland package.

No audio or device busy: choose the intended output in AUDIO / MIDI. On a desktop already using PipeWire, pipewire-alsa provides ALSA routing through it; select the default device if the hardware device is occupied by another audio server. Use JACK only with a working JACK-compatible server. Begin at 48 kHz and 256 or 512 samples, and try the built-in output to isolate an interface problem. Arch PipeWire ALSA package.

MIDI is silent: enable the controller under Active MIDI inputs, and try KEYBOARD to distinguish MIDI setup from audio setup. If launch still fails, run the launcher in a terminal and send Kevin the exact message, distribution, desktop/session and audio device. Linux remains UNVERIFIED until real desktop playback and MIDI have been confirmed.

Updating

Save your patch, close KB-09, download the latest Linux ZIP and replace the extracted files. Presets and audio/MIDI preferences in your user account are retained. Keep personal presets you saved inside an old download folder before replacing it. This is a standalone-only package.

Send bugs

Use the manual's bug report and include your distribution, desktop/session (X11 or Wayland), audio setup, controller and a screenshot if useful. Internet is needed only for online features; the synth and manual work offline.
