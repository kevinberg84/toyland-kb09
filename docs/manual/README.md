# Toyland KB-09 user guide

Open `index.html` in a browser. Keep `styles.css` and the complete `assets/` folder alongside it. The guide uses local images and system fonts, so its contents, instructions and pictures work offline. Links to DAW vendors require an internet connection.

The guide covers the Windows and Mac instruments and standalone apps, Linux standalone setup, AGE, external envelope filtering, presets, display gestures and DAW setup. Format availability is stated in the installation section.

Use **Print / Save PDF** for a printable copy. The browser expands the troubleshooting answers for printing and restores their earlier state afterward. HTML is the supplied navigable manual; there is no separately reviewed PDF edition.

Run `tools/make_manual_html.py` to regenerate the self-contained `User Manual.html` after source edits. For the support guide, package `index.html`, `styles.css` and its referenced assets, including the current panel screenshot. The `qa/` and `reference/` folders contain development material and should be excluded from the consumer package.
