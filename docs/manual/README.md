# Toyland KB-09 user guide — Windows 0.13.2

Open `index.html` in a browser. Keep `styles.css` and the complete `assets/` folder alongside it. The guide uses local images and system fonts, so its contents, instructions and pictures work offline. Links to DAW vendors require an internet connection.

The guide covers the Windows VST3 instrument and standalone app, including AGE, external audio filtering, the envelope follower, presets, display sizes and DAW setup. AU and AAX availability is stated in the installation section.

Use **Print / Save PDF** for a printable copy. The browser expands the troubleshooting answers for printing and restores their earlier state afterward. HTML is the supplied navigable manual; there is no separately reviewed PDF edition.

For packaging, include `index.html`, `styles.css`, `assets/marks.png` and `assets/panel-0.13.2.png`. The `qa/` and `reference/` folders contain historical development material and should be excluded from the consumer package.
